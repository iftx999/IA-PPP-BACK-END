# 0005 · Java 21 LTS em vez de Java 25

**Contexto.** O doc 09 recomenda Java 25 LTS e aceita Java 21. O ambiente atual tem o JDK 21 instalado.

**Decisão.** Java 21 LTS com Spring Boot 4.1. O código evita APIs em preview.

**Consequências.** A migração para o 25 é trocar `java.version` e a imagem do CI, e pode ser feita quando o
ambiente de produção tiver o JDK 25.
